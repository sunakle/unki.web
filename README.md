# Unki

Веб-версия программы для интервальных повторений в стиле [Anki](https://apps.ankiweb.net/): колоды, карточки, статистика, тот же принцип «Снова / Трудно / Хорошо / Легко» и почти такой же интерфейс. Работает целиком в браузере — без сервера и без регистрации.

Данные хранятся в браузере (IndexedDB) и никуда не отправляются.

## Что уже умеет

- **Колоды** любой вложенности (`Язык::Глаголы`), счётчики «Новые / Изучаемые / К повторению», допзанятия.
- **Повторение**: планировщик в духе Anki (шаги изучения, интервал перевода, лёгкость, «пиявки», переучивание, откладывание карточек одной записи), подсказки интервалов под кнопками, отмена ответа, флажки, отметки, исключение и откладывание карточек.
- **Типы записей**: «Простая», «Простая (с обратной карточкой)», «…с обратной по выбору», «…с вводом ответа», «Задание с пропусками» (cloze). Свои типы, поля и шаблоны `{{Поле}}`, `{{#Поле}}…{{/Поле}}`, `{{cloze:…}}`, `{{type:…}}`, `{{hint:…}}`, CSS карточки.
- **Окно «Добавить»** и редактор: форматирование, цвета, списки, вставка изображений, запись звука, метки с автодополнением, проверка дубликатов.
- **Список карточек** (как «Браузер» в Anki): боковая панель, режимы «Карточки/Записи», настраиваемые колонки, сортировка, поиск с тем же синтаксисом (`deck:`, `tag:`, `is:due`, `prop:ivl>10`, `added:7`, `re:…`, …), групповые операции, поиск и замена, дубликаты, редактор записи рядом.
- **Статистика**: сегодня, прогноз, календарь, повторения, количество карточек, интервалы, лёгкость, часы, кнопки ответов, добавление — для колоды или всей коллекции.
- **Параметры колоды** (наборы настроек) и общие настройки: тема (светлая/тёмная/как в системе), масштаб интерфейса, начало дня и др.
- **Импорт и экспорт**: `.txt`/`.csv`/`.tsv` (в том числе «Записи в виде простого текста» из Anki — с колонками колоды и типа записи), `.unki.json` с расписанием, резервные копии.
- Горячие клавиши как в Anki (`D`, `A`, `B`, `T`, `Y`, `/`, `Пробел`, `1–4`, `Z`, `E`, `*`, `F1–F7` …), полный список — «Справка → Горячие клавиши».

## Как запустить

Нужен только статический хостинг — сборки нет.

**GitHub Pages:** *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save*. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/unki.web/`.

**Локально:**

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

(Открывать `index.html` двойным щелчком нельзя: браузеры не разрешают ES-модули с `file://`.)

## Устройство проекта

```
index.html        оболочка страницы
css/app.css       стили, светлая и тёмная темы
js/main.js        меню, навигация, горячие клавиши
js/store.js       коллекция и сохранение в IndexedDB, отмена действий
js/sched.js       планировщик (аналог SM-2 из Anki v2)
js/models.js      типы записей, шаблоны, cloze, безопасный HTML
js/decks.js       экран колод и экран колоды
js/review.js      повторение
js/add.js, editor.js, notetypes.js   добавление, редактор, типы записей
js/browser.js, search.js             список карточек и поиск
js/stats.js, info.js                 статистика, информация о карточке
js/options.js, io.js, tools.js       параметры, импорт/экспорт, инструменты
```

Карточки отображаются в изолированном `iframe` без выполнения скриптов; HTML записей очищается от опасных тегов и атрибутов.

## Ограничения

- Нет облачной синхронизации и входа в AnkiWeb: переносите данные через резервные копии (*Файл → Создать резервную копию*).
- Файлы `.apkg` / `.colpkg` напрямую не читаются: в Anki выберите *Файл → Экспорт → Записи в простом тексте*.
- Пока нет: FSRS, скрытых частей изображений, фильтрованных колод, формул LaTeX/MathJax, дополнений.
- Данные привязаны к адресу сайта и браузеру. Очистка данных сайта удалит коллекцию — делайте копии.

Unki — самостоятельный проект и не связан с создателями Anki.
